# 🍔 FoodFlow: MERN Food Delivery Platform

FoodFlow is a full-stack food ordering platform inspired by apps like Zomato & Swiggy.
It supports multiple user roles: Admin, Restaurant, and Customer with role-based dashboards and full CRUD functionality.

Built using the MERN stack and designed as a project showcase demonstrating real-world backend + frontend integration.

🌐 Live Demo: [foodflow-lzfy.onrender.com](https://foodflow-lzfy.onrender.com)

---
## 🚀 Features


🔐 Authentication & Roles
---

- User signup & login

- Role-based access control:

  - Admin

  - Restaurant

  - Customer

- Protected routes (frontend + backend)

- JWT-based authentication
---

🧑‍💼 Admin Panel
---

- View all users

- View all restaurants

- View all orders

---

🍽️ Restaurant Panel
---

- Create & update restaurant profile (Settings)

- Menu management (CRUD)

  - Add menu items

  - Edit menu items

  - Delete menu items

  - View customer orders

  - Update order status

- Logout functionality
---

🛒 Customer Panel
---

- Browse restaurants

- View restaurant menus

- Place orders

- Cancel orders

---

🧱 Tech Stack
---
Frontend
--

- React (JavaScript)

- React Router DOM

- Axios

- Bootstrap

- Material UI (MUI)

Backend
--
